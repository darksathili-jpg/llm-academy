Apprendre les LLM avec Microduck

Un seul portail pour parcourir les modules pédagogiques disponibles, des notions de base aux calculs et à l'analyse critique.

Version expérimentale. Les tests du parcours Softmax R2 ont été déclarés réussis sur le poste du responsable, mais cela ne valide pas encore la maîtrise chez des élèves débutants. Les autres pilotes ont des statuts différents. Cette page n'est pas une certification ni le site public officiel.

Parcours conseillé pour débuter

Pour comprendre les calculs d'attention : tokens → embeddings → scores/softmax → masque causal → Q/K/V → attention réelle. Les exemples utilisent des données simplifiées lorsqu'elles ne proviennent pas d'un modèle entraîné. Microduck accompagne l'apprentissage ; les indices disparaissent progressivement.

Calculatrice : l'émulateur NumWorks officiel est proposé à la demande dans les activités de calcul, sans téléchargement automatique d'un service tiers.

Enseignants : préparer et vérifier une séance

Les modules comportent des pistes de remédiation, mais les réponses ouvertes ne sont pas corrigées scientifiquement par le navigateur. Utiliser le barème dans le dépôt GitHub si le document est disponible dans votre environnement ; pour la version en ligne, consulter le lien documentaire depuis le README du dépôt.

Deux espaces complémentaires restent nécessaires : un véritable recueil de productions anonymisées et une étude différée de compréhension. Ne pas confondre le nombre de tests Playwright et le nombre de compétences acquises.
