Attention réelle : laboratoire à générer

Ce laboratoire n'est pas inclus dans le paquet statique actuel. Il nécessite d'exécuter le script d'export du Mini-Transformer PyTorch afin de produire de véritables matrices d'attention. Le remplacer par des nombres inventés serait scientifiquement trompeur.

Depuis la racine du dépôt, sur la branche pédagogique et dans un environnement Python contenant les dépendances de l'expérience :

python experiments/mini_transformer/export_microduck_attention.py

Le script écrit normalement public/pilotes/microduck-attention-reelle-r1/index.html. Il faut ensuite reconstruire le site avec npm run build pour inclure ce pilote dans la prévisualisation.

Dans l'attente, poursuivre avec le laboratoire numérique Q/K/V. Les matrices de cette activité sont des données pédagogiques et non celles d'un modèle entraîné.

Statut : non généré dans le dépôt, donc non validé pour le paquet de prévisualisation.
