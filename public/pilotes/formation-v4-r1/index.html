LLM ACADEMY / LABORATOIRE V4-R1 / PROTOTYPE EXPÉRIMENTAL

Le premier modèle qui écrit vraiment.

Un modèle de langage à bigrammes apprend à partir du corpus, calcule des fréquences conditionnelles et tire les mots suivants. Ce n’est pas un LLM : il ne connaît qu’un mot de contexte.

01 · Corpus d’entraînement

Modifie le texte puis entraîne le modèle. Chaque phrase terminée par un point redémarre le contexte.

02 · Paramètres de génération

Même corpus + même graine + mêmes réglages = même sortie. Une autre graine peut donner une autre suite. Le modèle peut produire une phrase absurde ou inachevée.

03 · Résultat effectivement généré

Entraîne le modèle, puis génère une phrase.

04 · Trace explicable des décisions

Pour chaque transition : mot précédent → candidats appris, probabilités après température et top-k → mot tiré. Les nombres proviennent des comptes du corpus, pas d'une liste de résultats prédéfinis.

05 · À comprendre

Entraîner signifie ici compter les transitions observées. Avec un contexte « le », le modèle apprend les mots trouvés après « le ». Générer signifie échantillonner successivement cette distribution. Les bigrammes ne conservent pas la phrase entière : c’est précisément une limitation que l’on comparera ensuite aux Transformers.

Défi de transfert : ajoute trois phrases contenant « le robot », réentraîne le modèle, puis explique pourquoi la probabilité du mot « robot » après « le » a changé. Compare top-k=1 et top-k=3 avec la même graine. Aucun clic ne certifie la maîtrise : rédige tes observations et tes calculs.

Prototype autonome · Calcul local · Aucune requête réseau dans le laboratoire · Aucun compte utilisateur. Ne saisis pas de données personnelles dans le corpus.
