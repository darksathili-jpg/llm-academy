2. Trois rôles pour trois vecteurs

Q (Query) est le vecteur de requête de la position qui consulte. K (Key) est le vecteur comparé à Q pour calculer la compatibilité. V (Value) fournit l'information combinée à la fin.

Q₁=(1,0), K₀=(1,0), K₁=(0,1), K₂=(5,0). V₀=(2,0), V₁=(0,4), V₂=(99,99).

Pour chaque position autorisée, le score brut est le produit scalaire Q₁ · Kⱼ. Comme la dimension des clés vaut 2, le score normalisé est divisé par √2.

Rappel : (a,b)·(c,d)=ac+bd.

3. Masquer, puis normaliser

Les scores bruts sont (1, 0, 5). Le score de la position future 2 est interdit, même s'il est le plus élevé. Les logits autorisés sont donc (1/√2, 0).

p₀ = exp(1/√2) / [exp(1/√2)+exp(0)] ; p₁ = exp(0) / [exp(1/√2)+exp(0)] ; p₂ = 0.

5. Vérifier avec Python, puis expliquer seul

Ce code Python reproduit les calculs numériques. Il ne nécessite pas PyTorch.

from math import exp, sqrt
q = (1.0, 0.0)
keys = [(1.0, 0.0), (0.0, 1.0), (5.0, 0.0)]
values = [(2.0, 0.0), (0.0, 4.0), (99.0, 99.0)]
position = 1
scores = [sum(a*b for a, b in zip(q, k)) / sqrt(2)
          for k in keys[:position + 1]]
weights = [exp(s - max(scores)) for s in scores]
total = sum(weights)
weights = [w / total for w in weights]
output = tuple(sum(weights[j] * values[j][d]
                   for j in range(position + 1)) for d in range(2))
print(weights, output)

Fiche enseignant — définitions, exactitude et limites

Dans un Transformer, Q, K et V résultent en général de transformations linéaires apprises des représentations de chaque position. Cette activité fixe ces vecteurs pour rendre le calcul contrôlable. Les scores sont QKᵀ/√dₖ ; les positions futures sont masquées ; la softmax porte sur les scores autorisés ; la sortie est une combinaison pondérée de V. Ce résultat n'est pas encore une probabilité du prochain caractère.

Erreurs à détecter : inclure le futur parce que son score est élevé ; confondre K et V ; oublier la mise à l'échelle ; normaliser avant le masque ; confondre la somme pondérée avec une prédiction de token.
