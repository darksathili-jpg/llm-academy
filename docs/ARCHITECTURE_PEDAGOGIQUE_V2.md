# Architecture pédagogique V2

Trois espaces et des moteurs communs. L'atelier Terminale présente dix investigations : crédibilité, tokens, probabilités, contexte, représentation, attention, apprentissage, génération, erreurs, fiabilité. Chaque fiche contient problème, public, durée proposée, prérequis, objectif observable, notions, consigne, manipulation, observation, explication, erreurs, trois aides, correction, critères, transfert et approfondissement.

Huit étapes : situation → hypothèse → expérience → observation → explication → programmation → transfert → évaluation. Aucune formule avancée obligatoire avant l'observation. Une réponse libre reçoit une grille, pas une note prétendument intelligente.

Le studio sert les séances 60/120/180/360 minutes, avec publics hétérogènes. Les durées sont des propositions de conduite, à ajuster après usage réel. Vue projetée sans notes privées ; notes dans une fenêtre de coulisses séparée. Les corrections ne sont visibles qu'après action explicite.

Le laboratoire distingue manipulation intuitive et calcul scientifique. Les anciens modules et carnets restent accessibles. Les moteurs existants sont réutilisés. Les nouvelles traces d'investigation sont versionnées et exportables ; la migration ne supprime pas l'ancien carnet.
